# keybindings reference

this file does nothing. it's just for my own reference
you can't script keybindings in LXQt :(

## keybindings

### SHIFT

- **SHIFT+F7**: `pkexec lxqt-backlight_backend --dec`
- **SHIFT+F8**: `pkexec lxqt-backlight_backend --inc`

### ALT

- **CTRL+ALT+0**: `~/.local/bin/recordscreen`
- **CTRL+ALT+9**: `~/.local/bin/dict`
- **CTRL+ALT+E**: `~/.local/bin/shmoji dmenu`
- **CTRL+ALT+P**: `~/.local/bin/passmenu`
- **CTRL+ALT+[**: `~/.local/bin/pick`

### WIN

- **CTRL+WIN+T**: `~/.local/bin/tempmenu menu`
- **CTRL+WIN+=**: `~/.local/bin/mathcalc`

### PRTSC

- **CTRL+PRTSC**: `~/.local/bin/screenshotpick`
- **PRTSC**: `~/.local/bin/screenshot`

### misc

- **CTRL+SHIFT+ALT+E**: `~/.local/bin/kaomoji menu`
